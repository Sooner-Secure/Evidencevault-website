00 / YOUR DATA

Your evidence.
Not our data.

Evidence Vault collects no data from the app. No app analytics, no telemetry, and no project files sent to Sooner Secure. Your password-encrypted project database stays under your control.

02 / THE WORKFLOW

From first upload
to final handoff.

Evidence Vault keeps each project in its own password-encrypted database file, then documents how evidence is handled inside it.

01▣

Create a project vault.

Start a project database file and protect it with a password. Your incident or test has a dedicated place to live.

PROJECT FILE ↗
02⌁

Collect with context.

Add files to the project. Evidence Vault records interactions such as viewing and exporting, with the relevant file hash in the chain of custody.

ACCESS HISTORY ↗
03↗

Export what matters.

Export the entire project or an individual file. Single-file exports include that file’s chain of custody document.

03 / INSIDE THE APP

A record of what happened to the file.

The chain of custody is part of the working project, not an afterthought at export time.

  • 01
    Activity, in sequence

    See when a file was uploaded, viewed, exported, or otherwise handled.

  • 02
    Hashes alongside events

    Associate actions with the relevant file hash for a clearer integrity trail.

  • 03
    Focused exports

    Share a single file and its own custody document when the whole project is more than the recipient needs.
